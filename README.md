# Informatics Tasks

Решения 10 задач по Python. Каждая задача находится в отдельном `.py` файле.

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Запустите нужный файл, например:
   `python task_01_passport.py`

## Перед сдачей
- В `task_01_passport.py` замените номер группы на свой.
- Проверьте значения исходных данных и при необходимости измените их.
- Задачи 3 и 4 реализуют конвертер температуры и рабочий график согласно формулировкам в PDF.
- Требование по Git: делайте осмысленные коммиты по мере работы. Не создавайте фиктивную историю задним числом.

## Пример истории Git
```bash
git init
git add README.md
git commit -m "Добавлено описание проекта"

git add task_01_passport.py
git commit -m "Создан цифровой паспорт объекта"
# Далее для каждой задачи: отдельный коммит создания файла и отдельный коммит реализации логики.
```
