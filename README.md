## Состав репозитория

- `task_01_passport.py` — цифровой паспорт строительного объекта.
- `task_02_room_calc.py` — площадь пола и стен, объём помещения и стоимость покраски.
- `task_03_estimate_compare.py` — конвертер температуры и состояние воды.
- `task_04_foundation_load.py` — день недели и режим работы.
- `task_05_materials_vat.py` — калькулятор скидки на материалы.
- `task_06_materials_catalog.py` — операции со списком материалов.
- `task_07_price_dict.py` — прайс-лист на основе словаря.
- `task_08_set_analysis.py` — анализ материалов подрядчиков с помощью множеств.
- `task_09_address_clean.py` — нормализация адресов.
- `task_10_warehouse_system.py` — учёт складских запасов и выдача материалов.

## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

Откройте терминал в папке репозитория и запустите нужный файл, например:

```bash
python task_01_passport.py
python task_03_estimate_compare.py
```

Задачи 3–5 запрашивают ввод в консоли. В задаче 2 размеры помещения заданы переменными в начале файла, их можно поменять.

## Требования к оформлению

Каждая задача находится в отдельном `.py` файле. В коде есть комментарии, вывод форматирован, используются понятные имена переменных. Для выполнения требования по истории Git следует делать отдельные осмысленные коммиты по мере работы над каждой задачей.

## Пример плана коммитов

Для каждой задачи рекомендуется не менее двух коммитов:
1. `Add task_01_passport.py: initial structure` — создание файла и исходных переменных.
2. `Implement task_01_passport.py output` — логика и форматированный вывод.
3. `Improve task_01_passport.py comments and formatting` — комментарии и улучшения.

Не создавайте один общий коммит вместо истории работы над всеми задачами.
